Лабораторная работа № 4. Создание страницы определенной записи

Цель из LMS: выполнить запросы на выборку с использованием операторов и функций.
Содержание работы по методичке: создать страницу отдельной статьи и оформить обе страницы.
Выполнены оба пункта на базе блога из лабораторной № 3.
Python 3.12 и Django 5.2.17 используются по согласованию.
Репозиторий: https://github.com/aerial016/pis-labs-python-django/tree/main/lab4

Состав:
blog/ — отдельный проект Django, приложение articles и готовая база db_blog с пятью статьями.
queries.sql — пять запросов SELECT с операторами и функциями SQLite.
query_results.txt — фактические результаты выполненных запросов.
run_queries.py — запуск этих же запросов в режиме чтения.

Результат по методичке:
Адрес статьи имеет вид /article/5/; идентификатор в маршруте — только цифры.
get_article получает статью по id; при отсутствии записи возвращается HTTP 404.
Заголовки в архиве ведут на отдельные страницы статей.
На странице статьи выводится полный текст и ссылка «Все записи».
К обоим шаблонам подключён articles/static/css/article.css.
Классы body различаются: archive и article.
Оформление соответствует макетам: зелёный фон #1abc9c, белый текст,
логотип, заголовки, автор слева и дата справа; в архиве логотип по центру,
на странице отдельной записи логотип слева, ссылка справа.

Запуск из папки lab4:
python -m pip install -r requirements.txt
python run_queries.py
cd blog
python manage.py runserver 127.0.0.1:8764

Архив: http://127.0.0.1:8764/
Пример отдельной статьи: http://127.0.0.1:8764/article/5/
Административное приложение: http://127.0.0.1:8764/admin/
Учебный логин и пароль — в blog/accounts.txt.
База уже заполнена. Запросы SELECT не изменяют данные.

Адаптация примера маршрута из методички для Django 5.2:
Для регулярного выражения используется re_path вместо path; добавлен завершающий /,
чтобы адрес соответствовал приведённому в задании примеру /article/5/.
Документация Django: https://docs.djangoproject.com/en/5.2/topics/http/urls/
Документация функций SQLite: https://www.sqlite.org/lang_corefunc.html
