Лабораторная работа № 7. Изучение основ JavaScript, создание простейших функций и использование базовых операторов

Python 3.12, Django 5.2.17, SQLite.
Репозиторий: https://github.com/aerial016/pis-labs-python-django/tree/main/lab7

Запуск из папки lab7:
python -m pip install -r requirements.txt
cd blog
python manage.py migrate
python manage.py runserver 127.0.0.1:8767

Архив статей: http://127.0.0.1:8767/
Вход: http://127.0.0.1:8767/admin/
Логин и пароль находятся в blog/accounts.txt.

Введите группу или порог среднего балла в поле на странице архива и нажмите соответствующую кнопку фильтрации.
Массив студентов и таблицы результатов выводятся в консоль браузера (F12 → Console).
Фильтрация по среднему баллу использует строгое условие «выше порога».
Кнопка «свернуть» скрывает автора, дату и текст статьи; «развернуть» возвращает их.

triggers.sql содержит таблицу журнала и три триггера: добавление, изменение заголовка, удаление статьи.
Триггеры устанавливаются миграцией 0002_article_triggers и уже созданы в готовой базе blog/db_blog.
commands.sql содержит выполненные команды; trigger_results.txt — результаты.
Журнал article_changes хранит три записи: INSERT, UPDATE, DELETE.
Для повторного выполнения из папки lab7: python run_commands.py
При повторном выполнении в журнал добавляются ещё три записи.
